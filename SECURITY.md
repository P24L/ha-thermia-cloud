# Security policy

## Reporting a vulnerability

Please report security problems **privately** through GitHub's *Security → Report a vulnerability* on this repository, not in a public issue. Include what you found and how to reproduce it; do not include your own credentials.

You can expect an acknowledgement within a few days. This is a volunteer project, so fixes are best effort.

## Scope

- Handling of credentials and tokens (login, refresh, storage, logging, diagnostics redaction).
- Anything that could write to a heat pump unintentionally.

The Thermia cloud itself is out of scope; report problems with it to the vendor.

## Supported versions

Only the latest release.
